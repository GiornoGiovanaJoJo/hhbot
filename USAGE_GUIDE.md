🤖 Инструкция по использованию HH Auto Response Bot
📋 Что нужно для запуска
1. Telegram Bot Token
Перейдите к @BotFather в Telegram

Создайте нового бота командой /newbot

Придумайте название и имя пользователя для бота

Скопируйте полученный токен

2. HeadHunter API приложение
Зарегистрируйтесь на https://dev.hh.ru

Создайте новое приложение

В поле "Redirect URI" укажите: http://localhost:8000/auth/callback

После одобрения получите Client ID и Client Secret

3. Настройка окружения
Создайте файл .env на основе .env.example:

text
TELEGRAM_BOT_TOKEN=ваш_токен_бота
HH_CLIENT_ID=ваш_client_id
HH_CLIENT_SECRET=ваш_client_secret
HH_REDIRECT_URI=http://localhost:8000/auth/callback
🚀 Запуск бота
Установите Python 3.12

Установите зависимости: pip install -r requirements.txt

Создайте файл .env с вашими данными

Запустите: python main.py

💬 Команды бота
Базовые команды:
/start - Запуск бота и приветствие

/help - Список всех команд

/auth - Авторизация в HeadHunter

Настройки и профиль:
/profile - Просмотр вашего профиля и резюме

/settings - Настройка критериев поиска вакансий

/resume - Выбор активного резюме

Поиск и отклики:
/search - Поиск подходящих вакансий

/auto_start - Запустить автоматические отклики

/auto_stop - Остановить автоматические отклики

/status - Текущий статус работы бота

Статистика:
/stats - Общая статистика откликов

/today - Статистика за сегодня

/history - История последних откликов

🔧 Первичная настройка (пошагово)
Шаг 1: Авторизация
Запустите бота командой /start

Нажмите /auth для авторизации в HeadHunter

Бот пришлет вам ссылку - перейдите по ней

Войдите в свой аккаунт HH и разрешите доступ

Скопируйте URL страницы, на которую вас перенаправили

Отправьте этот URL боту

Шаг 2: Выбор резюме
Выполните /profile чтобы увидеть ваши резюме

Используйте /resume для выбора активного резюме

Шаг 3: Настройка критериев
Выполните /settings и настройте:

Ключевые слова: навыки и технологии из вашего резюме

Регион: где хотите работать

Зарплатные ожидания: минимальный уровень

Опыт работы: ваш уровень

Тип занятости: полная/частичная/удаленка

Исключения: компании/слова, которые нужно игнорировать

Шаг 4: Тестовый поиск
Выполните /search для поиска подходящих вакансий

Проверьте результаты и при необходимости скорректируйте настройки

Шаг 5: Автоотклики
Запустите автоматический режим: /auto_start

Бот будет искать и откликаться на вакансии каждые 30-60 минут

Проверяйте статус: /status

📊 Алгоритм работы бота
Анализ соответствия:
Опыт работы (40% веса) - соответствие требованиям по опыту

Навыки (50% веса) - совпадение ключевых навыков

Зарплата (10% веса) - совместимость зарплатных ожиданий

Критерии отклика:
Общий скор соответствия ≥ 60%

Не откликались на эту вакансию ранее

Не превышен дневной лимит (200 откликов)

Вакансия соответствует настройкам фильтров

Автоматическое сопроводительное письмо:
Бот генерирует персонализированные письма на основе:

Названия вакансии и компании

Ключевых требований из описания

Ваших навыков из резюме

⚙️ Дополнительные настройки
В файле .env можно настроить:
text
# Лимиты и задержки
MAX_RESPONSES_PER_DAY=200

SEARCH_DELAY_SECONDS=60

# Поиск вакансий

# Логирование

🛡️ Безопасность
Токены HH хранятся в зашифрованном виде

Соблюдаются лимиты API (не более 200 откликов в день)

Задержки между запросами предотвращают блокировку

Логирование всех действий для контроля

📱 Уведомления
Бот присылает уведомления о:

Найденных подходящих вакансиях

Отправленных откликах

Ошибках или проблемах

Достижении дневного лимита откликов

Изменении статуса откликов (приглашение на собеседование)

⚠️ Ограничения
200 откликов в день - лимит HeadHunter API

Задержка 30 секунд между откликами - для безопасности

Только публичные вакансии - закрытые вакансии недоступны

Один активный аккаунт - бот работает с одним HH профилем

🆘 Поддержка
Частые проблемы:
"Токен недействителен" - выполните повторную авторизацию /auth

"Превышен лимит" - ждите до следующего дня

"Нет подходящих вакансий" - скорректируйте критерии в /settings

Логи:
Проверьте файл hh_bot.log для диагностики проблем

Команды диагностики:
/status - текущее состояние бота

/profile - проверка авторизации и резюме

/today - статистика работы за день
