🔐 QUICK SETUP INSTRUCTIONS FOR .env FILE
=============================================

STEP 1: Copy the template
  $ cp .env.example .env

STEP 2: Get Telegram Bot Token
  - Open Telegram and find @BotFather
  - Send /newbot
  - Follow the prompts
  - Copy the token you receive
  - Paste in .env: TELEGRAM_BOT_TOKEN=<token>
  - Token format: 123456789:ABCdefGHIjklMNOpqrSTuvwxyzABCDEFghi

STEP 3: Get HeadHunter Credentials
  - Go to https://dev.hh.ru/admin/applications
  - Sign in with HeadHunter account
  - Click "Create application" or "Создать приложение"
  - Name: HH Bot Recruiting Tool
  - Redirect URI: http://localhost:8000/auth/callback
  - Copy Client ID and Client Secret
  - Paste in .env:
    HH_CLIENT_ID=<your_client_id>
    HH_CLIENT_SECRET=<your_client_secret>

STEP 4: Get Your Telegram Admin Chat ID
  - Find @userinfobot in Telegram
  - Send any message
  - Copy the ID from response
  - Paste in .env: ADMIN_CHAT_ID=<your_id>

STEP 5: Verify Setup
  $ git status | grep ".env"
  (Should show .env as untracked, not staged)
  
  $ cat .gitignore | grep "^.env"
  (Should show .env is protected)

STEP 6: Test the Bot
  $ python main.py
  (Send /start command to your bot in Telegram)

STEP 7: Check Logs
  $ tail -f hh_bot.log

퉪️ SECURITY WARNINGS

  ⚠️  NEVER COMMIT .env FILE
  ⚠️  NEVER SHARE YOUR TOKENS
  ⚠️  NEVER PUSH TO GITHUB
  ⚠️  NEVER EMAIL CREDENTIALS
  ⚠️  USE PASSWORD MANAGER FOR BACKUP

🚨 IF TOKEN LEAKED

  1. IMMEDIATELY revoke in @BotFather
  2. Get new token
  3. Update .env
  4. Restart bot
  5. Delete old token (automatic in 30 seconds)
